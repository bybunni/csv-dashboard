## Highlights
- Added **multi-plot support** for 2D and 3D tabs — create multiple independent plots per tab, each with its own axis, series, and subfilter configuration.

## What's New
- **Multiple plots per tab**
  - Click "+ Add Plot" to add additional 2D or 3D plots alongside the first.
  - Each plot has independent axis, series, style, and subfilter settings.
  - Plots render in a responsive wrapping grid that collapses to a single column on narrow screens.
- **Plot selection and editing**
  - Click a plot to select it; the sidebar controls switch to edit that plot's parameters.
  - Active plot is highlighted with an accent border.
- **Plot removal**
  - Close button (X) on each plot allows removal; hidden when only one plot remains.
- **Dynamic plot height**
  - Plot surfaces shrink automatically when more than two plots are present to keep the grid compact.
- **Preset format v2**
  - Presets now save `plots2d` and `plots3d` arrays instead of singular `plot2d`/`plot3d`.
  - Backward-compatible: loading a v1 preset with singular `plot2d`/`plot3d` wraps it into a single-element array.

## Fixes
- Fixed YAML parser rejecting bare `-` array items (dash on its own line without trailing content), which caused "Expected key/value mapping" errors when loading v2 multi-plot presets.
- Fixed e2e test selectors for per-slot plot legends replacing the removed global `#legend2d` / `#meta3d` elements.
