## Highlights
- Added an intuitive **Columns** control panel in the Data tab to hide/show entire columns.
- Improved table sizing so columns contract to content (including the Row index column), reducing wasted horizontal space.

## What's New
- **Column visibility controls**
  - Searchable column list for quick discovery.
  - Per-column visibility toggles.
  - `Show all` and `Hide all` bulk actions.
- **Visibility-aware behavior across the app**
  - Hidden columns are removed from spreadsheet rendering.
  - Sort, filter, and quick-stats selectors now only include visible columns.
  - 2D/3D plot selectors and plot subfilter selectors respect visible columns.
  - CSV export now exports the current visible-column view.
- **Preset support update**
  - YAML presets now save and re-apply visible column selections via `data.visibleColumns`.

## Quality
- Added end-to-end coverage for column hide/show behavior to prevent regressions.
