## Highlights
- Row-virtualized table renderer replaces full-table innerHTML, removing the row cap so all filtered rows are scrollable with smooth performance.

## What's New
- **Row-virtualized table renderer**
  - Only ~50 viewport rows (+ overscan buffer) are kept in the DOM at a time, replacing the previous approach of rendering up to 2,000 rows via `innerHTML`.
  - Top/bottom spacer `<tr>` elements maintain correct scroll height without affecting small-dataset behavior.
  - Row height is auto-calibrated after first render for pixel-accurate scrolling.
  - Scroll updates are throttled via `requestAnimationFrame`; container resizes trigger re-render via `ResizeObserver`.
  - The adaptive row limit, cell budget, and "showing first N" metadata suffix are removed since all rows are now accessible.
- **Simplified release artifact names**
  - Binaries are now named `csv-dashboard.exe` and `csv-dashboard.app.zip` (dropped platform suffixes).

## Fixes
- **Flicker-free scroll updates** — Tbody content is built into a detached element and swapped in atomically via `replaceChild`, eliminating a visible column-width relayout that caused row-index numbers to shift during vertical scrolling.

## Quality
- Full unit and e2e test suites pass after virtualization changes.
