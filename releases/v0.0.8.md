## Highlights
- Major performance pass for large/wide CSVs: Data-tab redraws are now substantially faster and more responsive under heavy filter/sort interaction.

## What's New
- **Render scheduling + scope reduction**
  - Data/plot renders are coalesced with `requestAnimationFrame` to avoid redundant redraw bursts.
  - Data filter and plot subfilter inputs are now debounced.
  - View updates are scoped to the active tab instead of redrawing hidden plot tabs.
- **Faster filter pipeline**
  - Added precompiled active-filter evaluation path so empty filters are not re-checked per row.
  - Numeric filter token parsing is cached in compiled filter structures rather than repeatedly re-parsed in hot loops.
- **Adaptive table render budget (major win for wide datasets)**
  - Table row cap now adapts to visible column count using a cell budget.
  - Very wide views render fewer rows per redraw, dramatically reducing DOM/layout work.
  - Per-cell tooltips are automatically disabled above high cell-count thresholds to reduce HTML payload.
- **2D plot scaling**
  - Auto-switch to Plotly `scattergl` when point counts exceed threshold for better high-density rendering.

## Fixes
- Improved row-index behavior and stress-test readiness with new large CSV fixture generation utilities for profiling/perf validation.
