## Highlights
- Hotfix: macOS standalone app no longer shows "damaged and can't be opened" on launch.

## Fixes
- **macOS Gatekeeper rejection** — The CI-built `.app` bundle was unsigned, causing macOS to reject it as "damaged" when downloaded. Added ad-hoc code signing (`codesign --force --deep -s -`) before packaging. Users may still need to right-click > Open on first launch.
